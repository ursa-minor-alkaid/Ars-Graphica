# matrix-multiplication-methods — 矩阵乘法计算方式机制图示例

本示例包含两幅图，分别对应参考笔记中矩阵乘法的两种计算视角，均由手绘草图复刻而来。配色统一取自 `tokens/visual-tokens.md` 的方案三「灰紫烟粉」（该方案的推荐场景即理论框架、概念结构、数学与物理学领域），兼作数学与物理学领域范例。

| 图 | 文件 | 内容 |
|---|---|---|
| 图一 | `figure.svg` | 矩阵的列图像：Ax = b，A 的各列被 x 的元素加权后相加 |
| 图二 | `matrix-multiply-row-col.svg` | 矩阵乘法「行 × 列」：A 的第 i 行 × B 的第 j 列 = C 的元素 c_ij |

两图共用同一套颜色分工：品牌色系（`--brand`）承担全图唯一焦点，次强调（`--accent`）承担第二类别，中性层（`--text` / `--text-muted`）承担结构。切换配色方案时替换各文件顶部声明块中的颜色值即可，几何坐标不受影响。

## 图一：矩阵的列图像 Ax = b（figure.svg）

演示 precision-svg.md 在数学表达类机制图上的完整应用，并示范 image-replication.md 第 3 节的手绘净线结构复刻。配色：A 的各列取品牌的深浅两档软底（`--brand-soft-strong` 与 `--brand-soft`）配 `--brand` 描边，x 的加权元素与指向各列的弧线用 `--brand` 实色承担全图唯一焦点，结果向量 b 走次强调的 `--accent` 系（`--accent-soft` 底、`--accent` 描边、`--accent-text` 文字），三个括号统一用中性层的 `--text-muted`。

图形由手绘草图复刻而来，执行 image-replication.md 第 3 节：保留「A 拆出各列 → x 的元素加权 → 弧线指回对应列 → 结果汇入 b」的连接拓扑与两处省略号结构，丢弃手写体、抖动线条、墨迹与徒手间距的不匀，输出规整几何、标准字体与严格对称的括号内边距。

对齐与净空校验：

- 括号内边距：A 左 108−96 = 12、右 344−332 = 12；b 左 680−668 = 12、右 744−732 = 12
- 列距：160→176 = 16，228→280 = 52（省略号走廊）
- x 内容上下留白：192−162 = 30，388−358 = 30，对称
- 画布水平居中：内容占 84~756，左右留白各 84
- viewBox 高度：最低元素为组标签基线 405，加安全距 45 得 450

弧线：

1. `M 424 206 C 400 90, 134 80, 134 168`：起点落在 x 的左括号竖线 x=424、高度取 x₁ 胶囊中心 206；终点为 col₁ 顶边中心 x=134，自 y=170 回退 2 至 168
2. `M 424 254 C 414 96, 202 132, 202 168`：起点高度取 x₂ 胶囊中心 254；终点为 col₂ 顶边中心 x=202

原图只画出第 1、2 两条对应关系，其余由 ⋮ 省略，因此弧线不覆盖 xₙ。两条弧线的控制点与各自终点同 x，末段切线垂直；弧线 1 全程位于弧线 2 上方，两者竖直间距不小于 18，无交叉。

### 可替换点

- 列数与维度：colₙ 与 ⋯ 表示任意多列；增删列条后须按 52 宽重算列距与括号跨度，括号内边距 12 保持不变，并同步核对 ⋯ 两侧留白是否相等
- 弧线条数：改为全量连线时，须为每条弧线分配独立走廊并重算各层峰值 y，禁止多条弧线共用一段起点
- 焦点迁移：把焦点从 x 的加权元素移到结果向量 b 时，须同步互换 brand 与 accent 的角色，保持全图唯一焦点不变
- 配色切换：替换顶部 token 声明块；「列条同色相两档、加权元素实色、结果向量次强调」的三层颜色逻辑保持不变
- 水平间距：A 的括号跨度由列数决定（现为 272），b 的跨度由单条列宽加两侧内边距决定（现为 100）；改动任一组宽度后须重算三组之间的水平间距，等号恒取 x 右括号与 b 左括号的中点

- 行列位置：i 行、j 列现取条带中心；改为非中心行列时须同步移动 A、B 中的条带与 C 中的交叉点，并重算两条引导线与四个标签
