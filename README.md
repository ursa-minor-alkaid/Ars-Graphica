# ars — ArsGraphica 精准图形生成 Skill

从 dynamic-ui 提纯的个人图形生成技能。输入文字描述或图片，输出独立静态 SVG 文件；核心保证：文字定位精确、元素对齐、箭头方向正确。

## 用法

- 激活命令：`/ars`，或直接下达明确的绘制、复刻指令
- 输入两类：
  - 文字描述：如"画一个登录流程图，包含验证码分支"
  - 图片：提供图片并要求复刻；默认忠实取原图颜色，指令"用我的配色"切换到 token 框架；原图为手绘时自动进入净线结构复刻（忽略手写体与线条歪斜抖动，输出达科研期刊配图水准）
- 输出：独立 `.svg` 文件，写入指定路径或当前工作目录；默认画布宽 960，可在指令中指定尺寸
- 配色：token 已填入默认方案“雾蓝燕麦”（低饱和莫兰迪系），另有四套备选（豆绿陶土、灰紫烟粉、赭红陶橙、赭黄橄榄），切换方法见下文配色框架

## 构成

| 文件 | 角色 |
|---|---|
| `SKILL.md` | 入口：激活方式、输出契约、工作流索引、输出前最终核对 |
| `guides/precision-svg.md` | 核心规范（所有任务强制前置）：坐标计划、文本度量、锚点、对齐、箭头、防重叠硬门禁 |
| `guides/text-to-figure.md` | 工作流一：文字描述转图形；含流程图、时序图、数据图表、机制图、对比图、架构图的分类型构图规则 |
| `guides/image-replication.md` | 工作流二：图片复刻；视觉解析四步、重建原则、手绘净线结构复刻（期刊配图质量标准）、取色与切换、忠实度自检、降级路径 |
| `tokens/visual-tokens.md` | 视觉 token 框架：颜色角色定义（已填入低饱和莫兰迪配色，三套预设方案）与非颜色 token 定值（字号、间距、圆角、字重） |

## 配色框架简介

token 体系把颜色分为六个角色层，每层承担一种且仅一种视觉职能：

| 角色层 | token | 职能 |
|---|---|---|
| 中性 | `--surface` `--surface-muted` `--text` `--text-muted` `--border` | 承担全部结构与信息：节点面、正文、边框、网格线。一幅图 90% 的面积应当是中性层 |
| 品牌焦点 | `--brand` `--brand-soft` `--brand-text` 等 | 承担全图唯一焦点：关键路径、推荐项、最高值。每幅图至多一个品牌焦点 |
| 图表系列 | `--chart-series-1..4` `--chart-other` | 承担同源数据对比（A/B/C/D 两个方案、四个渠道）。上限 4 个系列 + 1 个 Other，超出时收敛类别 |
| 次强调 | `--accent` | 承担真正异质的第二类别（与同源对比含义不同的另一维度） |
| 语义 | `--success` `--warning` `--danger` | 仅用于显式状态、风险、健康编码；普通流程里的"成功""失败"字样不触发语义色 |

预设方案五套，均为低饱和莫兰迪调，每套主视觉色相不超过两种：

| 方案 | 色相构成 | 适用场景 |
|---|---|---|
| 雾蓝燕麦（默认） | 灰蓝焦点 + 燕麦次强调 | 通用默认：流程图、架构图、数据图表；论文插图、技术文档 |
| 豆绿陶土 | 灰豆绿焦点 + 陶土次强调 | 生命科学、认知科学、心理与哲学内容；人文向演示 |
| 灰紫烟粉 | 灰紫焦点 + 烟粉次强调 | 理论框架、概念结构、语言学与分析哲学图形；冷调正式出版物插图 |
| 赭红陶橙 | 赭红焦点 + 陶橙次强调 | 工程流程、操作指引、行动与能量语义图形；暖调演示教学 |
| 赭黄橄榄 | 赭黄焦点 + 灰橄榄次强调 | 历史、文献、社会科学内容；教学科普、人文向演示 |

暖调方案与语义色存在天然色相邻近：赭红邻近 danger（砖红），赭黄邻近 warning（赭石）。这两套方案下同图使用状态编码时，为状态元素附加文字或图标区分，不依赖色相。

切换方法：打开 `tokens/visual-tokens.md`，用预设配色方案一节中所选方案的整套色值替换声明块中的颜色 token；语义色五套共用，无需更换。非颜色 token（字号 12/14/16px、间距 4~24、圆角 8/12/999）为定值，直接生效。

## 与原版 dynamic-ui 的差异

### 删除

- 场景路由与判断：原版 Scene Router、五场景分流、"是否值得可视化"的拒绝规则全部移除；显式命令即意图，激活即工作
- 内联渲染契约：PureShowWidget 工具调用、流式输出约束（streaming-first）、聊天内嵌 widget 结构（`data-dynamic-ui-widget`、`data-mounted`、根选择器规范）
- Chart.js 与全部外部依赖：CDN 白名单、canvas 容器、tooltip 外置、fallback 渐进增强
- 交互 JavaScript：toggle、filter、stepper 等全部交互模式与事件绑定规范
- 主题运行时契约：`data-widget-theme` 深浅切换、`prefers-color-scheme` 联动；深色模式降级为可选的留空框架
- 模板库：16 个 HTML widget 模板及其 manifest 路由、material 选择矩阵、fallback primitive 体系

### 保留并强化

- SVG 几何规范：viewBox 与安全区、坐标计划、防重叠硬门禁（gap 下限、禁穿行、禁遮挡）
- 标准 marker 箭头：`orient="auto"` 的 8×8 三角 marker 定义完整保留，并新增端点缩进规则（箭头尖不刺入节点边框）
- 文本度量：字符宽度估算表保留，新增中文全角按 fontSize 计、代码串修正系数
- token 角色体系：中性结构 + 品牌焦点 + 系列色 + 语义色门禁的完整逻辑保留；具体色值清空待填，主题预设表替换为自建指引
- 构图方法论：单一焦点、可读性优先、方向语义、复杂度预算、各图形类型的构图规则（流程、时序、数据、机制、对比、架构）从五个 scene 文件合并提纯
- 数据诚实原则：单位、舍入一致、估算标注、零基线、负值与类别数约束

### 新增

- 图片复刻工作流：视觉解析四步（布局识别、元素清单、颜色提取、比例测量）、必须一致与允许规范化的边界、忠实度自检
- 手绘输入的净线结构复刻：判定为手绘即强制执行，忽略手写体与线条歪斜抖动（复刻结构、不复刻笔触），输出以科研期刊配图为质量门槛
- 取色策略：复刻默认忠实取原图色，指令切换到 token 框架的角色映射表
- 独立文件输出契约：完整 SVG 文件结构（`<title>`/`<desc>`、`svg{}` token 声明、命名规则）
- 文本锚点与基线规范：`text-anchor` 三种语义的计算规则、基线垂直居中公式（`y = 中心 + 字号 × 0.35`）、多行 tspan 规范；原版缺失此部分，是文字偏差与错位的主要来源
- 对齐公式：同排对齐基准三选一、等距分布公式、连线端点的边缘锚定公式
- 端点缩进规则：箭头目标端点回退 1~2 单位，消除箭头压框
- 降级路径：图片超出矢量复刻边界（照片、渐变光效）时先确认抽象层级再动手；手绘输入除外，直接走净线结构复刻

### 载体变化总结

原版面向聊天内嵌的交互式 widget（HTML 片段 + JS + Chart.js），本技能面向独立静态 SVG 文件（无 JS、无依赖、任意嵌入）；原版靠场景路由决定画什么，本技能靠显式指令直接进入工作流，把规范预算全部投入到绘制的精确性上。
