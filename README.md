从 dynamic-ui 提纯的图形生成技能：输入文字描述或图片，输出独立静态 SVG 文件，保证文字定位精确、元素对齐、箭头方向正确。

## 项目介绍

技能接收文字描述与图片两类输入，产出独立静态 SVG 文件，把规范预算集中投在绘制的精确性上。

- **文字描述 → 图形**（`guides/text-to-figure.md`）：解析描述并判定图形类型（流程、时序、数据、机制、对比、架构），按对应类型的构图规则组织结构；缺少必要数据时先提问，不虚构数据。
- **图片 → 复刻**（`guides/image-replication.md`）：布局识别、元素清单、颜色提取、比例测量四步解析后重建；布局、文字、连线、配色须与原图一致，仅允许字体与细微装饰规范化。
- **手绘输入**：判定为手绘即强制进入净线结构复刻，保留结构与颜色语义，丢弃笔触、抖动、纸面痕迹，输出以科研期刊配图为门槛。
- **精确绘制规范**（`guides/precision-svg.md`）：所有任务强制前置，定义坐标计划、文本度量与节点尺寸、锚点与基线、对齐与等距分布、marker 箭头与端点缩进、防重叠门禁，以及输出前十项自检。
- **视觉 token**（`tokens/visual-tokens.md`）：颜色按中性、品牌焦点、图表系列、次强调、语义六个角色层分配；字号、间距、圆角、字重为非颜色定值；内置五套低饱和莫兰迪配色，默认填入「雾蓝燕麦」。
- **示例骨架**（`examples/`）：两个静态 SVG 示例（柱线组合图、容器架构图），可作起手骨架与规范对照样本。

## 使用

### 安装

- 将 `ars-graphica.zip` 上传到 Agent 客户端的技能上传/安装界面
- 或直接把 `ars-graphica.zip` 发送给模型，协助在客户端安装

### 激活

输入 `/ars`，或直接下达明确的绘制、复刻指令。显式命令即意图，技能不做"是否值得可视化"的判断，不做场景路由。

## 输出

### 输出契约

- 产物为完整独立的 `.svg` 文件（UTF-8），写入指定路径；未指定时写入当前工作目录
- 默认画布宽 960，高度按内容计算，指定尺寸时从其规定；文件含 `<title>` 与 `<desc>`
- 颜色一律 `var(--token)`，token 声明放在首个 `<style>` 块的 `svg {}` 选择器中
- 纯静态输出：无 `<script>`、无事件属性、无 CDN 引用、无外部库、无 HTML 页面壳

### 配色

token 中已填入默认方案「雾蓝燕麦」。切换方式：用所选方案的整套色值替换 token 声明块中的颜色 token；语义色五套共用，非颜色 token 为定值，直接生效。

| 方案             | 色相构成                | 适用场景                                                     |
| ---------------- | ----------------------- | ------------------------------------------------------------ |
| 雾蓝燕麦（默认） | 灰蓝焦点 + 燕麦次强调   | 通用默认：流程图、架构图、数据图表；论文插图、技术文档       |
| 豆绿陶土         | 灰豆绿焦点 + 陶土次强调 | 生命科学、认知科学、心理与哲学内容；人文向演示               |
| 灰紫烟粉         | 灰紫焦点 + 烟粉次强调   | 理论框架、概念结构、语言学与分析哲学图形；冷调正式出版物插图 |
| 赭红陶橙         | 赭红焦点 + 陶橙次强调   | 工程流程、操作指引、行动与能量语义图形；暖调演示教学         |
| 赭黄橄榄         | 赭黄焦点 + 灰橄榄次强调 | 历史、文献、社会科学内容；教学科普、人文向演示               |

图片复刻默认忠实取原图颜色，指令「用我的配色」时按角色映射表切换到 token 框架。暖调方案与语义色色相邻近（赭红邻 danger，赭黄邻 warning），同图使用状态编码时须为状态元素附加文字或图标区分。
