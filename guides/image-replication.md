# 工作流二：图片 → 复刻图形

用户输入一张图片，输出忠实复刻该图片的独立 SVG 文件。几何与定位规则以 `guides/precision-svg.md` 为准，本文件定义从图片到坐标的转换流程。

## 1. 视觉解析四步

复刻前按顺序完成以下解析，全部为内部推理，不输出到回复。图片整体模糊到无法辨认结构时，先向用户确认内容，并搜索网络查找同类图形作参考，再进入解析。

### 1.1 布局识别

- 整体网格：内容按几行几列组织；哪个方向是主流向
- 对齐基准：各元素是居中对齐、顶对齐还是底对齐
- 分组容器：哪些元素被边框或底色围成一个组；嵌套几层
- 留白分布：边距与元素间距的比例关系（用于反推 gap）

### 1.2 元素清单

逐个登记可见元素，形成清单：

- 文本：内容（逐字）、位置、字号层级（大/中/小）、颜色
- 形状：类型（矩形/圆/胶囊/菱形/自由曲线）、尺寸比例、填充色、描边色
- 连线：起点元素与终点元素、路径形状（直线/折线/曲线）、是否有箭头及方向、颜色与线型

清单中每个元素对应输出 SVG 中的一个 `<g>` 分组。

### 1.3 颜色提取

默认忠实取色：

- 从图片提取：背景色、主色（占面积最大的强调色）、辅色、文本色、边框色
- 每个色值记录为十六进制；截图或压缩图导致色值有噪声时取视觉主色
- 提取结果直接写入 SVG 的 token 声明块（结构沿用 `tokens/visual-tokens.md` 的角色名，值用提取色）

### 1.4 比例测量

- 选定图片中的两个参考点（如最左节点左缘与最右节点右缘），建立比例尺
- 元素位置与尺寸按比例映射到 viewBox 坐标：`输出坐标 = 图内测量值 / 参考宽度 × viewBox宽`
- 取整到整数坐标，避免小数像素
- 图片有固定纵横比（如幻灯片截图）时按原图比例设定 viewBox

## 2. 重建原则

必须与原图一致：

- 布局拓扑：行列表格结构、分组从属、流向
- 相对位置与相对尺寸：谁在上/下/左/右、谁大谁小
- 文字内容：逐字一致，包括标点与大小写
- 连线走向与端点：连接关系、路径形状、箭头方向
- 配色（默认模式下）：色相、明度、饱和度按提取值

允许规范化（不构成失真）：

- 字体族统一为 token 字体栈（原图字体无法复刻时取视觉最接近的层级关系）
- 细小装饰（阴影、噪点、图标内的细节）按主轮廓简化
- 线宽与描边统一到 1.5/1 附近（原图为极细或极粗描边时保留相对关系）

禁止擅自改动：

- 增删元素（原图没有的图例、标题、说明不得添加；原图有的不得"优化"掉）
- 改变层级（把原图的次要元素放大强调）
- 重排布局（按"更好看"的理由移动元素）

文本度量仍执行 precision-svg 2.1/2.2：复刻文本前先按字符宽度估算表验证原文宽度是否与测得的框宽匹配，映射坐标时以原图框宽为准；估算宽度超出框宽时缩短字号半档（不低于 11px）或按原图换行方式断行，禁止溢出。

---

## 3. 手绘输入：净线结构复刻（Clean-Line Structural Replication）

原图出现以下任一特征即判定为手绘输入，强制进入净线结构复刻模式：

- 手写体文字：连笔、字形不规则、同类标签字号不一
- 徒手线条：歪斜、抖动、粗细不匀、起收笔带顿点
- 徒手形状：轻微歪扭或不完全闭合的矩形、圆、菱形、箭头
- 纸面痕迹：铅笔底稿、涂抹、阴影线、污渍

判定为手绘后直接执行本模式，不进入第 6 节的降级协商。

### 3.1 复刻原则：复刻结构，不复刻笔触

必须保留（与第 2 节一致）：

- 布局拓扑、相对位置与从属关系
- 文字内容逐字一致
- 连线的连接关系与方向
- 颜色语义（墨色深浅映射为输出的描边与文本色）

必须丢弃（净化对照表）：

| 手绘特征 | 净化后的输出 |
|---|---|
| 手写体 | token 字体栈标准字体，按原图层级映射到 text-title / text-body / text-caption |
| 歪斜、抖动的线段 | 两端点之间的平直线段（端点按 1.4 节比例测量取定） |
| 徒手曲线 | 少量控制点的光滑贝塞尔曲线，走向与原图一致 |
| 歪扭形状 | 规整几何：矩形 rx=8、胶囊、圆角菱形，尺寸按比例测量 |
| 粗细不匀的描边 | 统一 stroke-width（1.5 主 / 1 辅） |
| 顿点、墨迹、涂抹、阴影线、污渍 | 全部移除，不留痕迹 |

归正规则：手绘噪声造成的轻微不齐与间距不匀按布局意图归正（同排对齐、等距分布）；原图明确表达的错位与交错布局属于布局意图，保留。

### 3.2 质量标准：科研期刊配图水准

净线复刻的输出以可直接用于科研期刊发表的配图为质量门槛，逐项核对：

1. 全部元素为规整矢量几何：直线平直、曲线光滑、形状完全闭合，对称部分真正对称
2. 排版执行 precision-svg 全部规范：对齐基准一致、间距相等、文本锚点与基线按公式计算
3. 文字为标准字体，层级仅用字号 token 三档（title / body / caption）表达，同类标签字号完全一致
4. 描边宽度全图至多两档（1.5 / 1），颜色遵循所用颜色模式的角色约束，无杂色
5. 输出中无任何手绘痕迹残留：无抖动、无粗细变化、无墨迹质感、无歪斜
6. 布局均衡：节点、连线、标签在 viewBox 内分布均匀，无局部拥挤或重心失衡

任一条不满足时回到坐标计划修正，禁止带病输出。

## 4. 颜色模式切换

| 模式 | 触发条件 | 行为 |
|---|---|---|
| 忠实取色（默认） | 未提及配色 | 从原图提取色值，直接使用 |
| 框架配色 | 用户指令"用我的配色/用 token 配色" | 按下表做角色映射，使用 token 已填色值 |

角色映射表（框架配色模式）：

| 原图角色 | token |
|---|---|
| 主强调色（原图的焦点元素色） | `--brand` |
| 同源系列色（多系列数据、多类别平级色） | `--chart-series-1..4` |
| 背景、面板底色 | `--surface` / `--surface-muted` |
| 正文与标题文字 | `--text` / `--text-muted` |
| 边框、分隔线、网格线 | `--border` |
| 绿/黄/红等状态色 | `--success` / `--warning` / `--danger` |

token 未填写而用户要求框架配色时，退回忠实取色并说明原因。

## 5. 忠实度自检

输出前对照原图逐区块核对：

1. 逐区块（左上→右下）核对：位置、尺寸比例、从属关系
2. 文字逐字核对，含大小写与标点
3. 连线逐条核对：两端元素、路径形状、箭头方向
4. 配色核对：默认模式下每个色值与提取值一致；框架模式下映射无遗漏
5. precision-svg 第 7 节自检清单全部通过
6. 净线结构复刻模式下：结构逐项与原图对应（连接关系、从属、文字逐字），同时第 3.2 节质量标准六项全部通过，输出无手写体、抖动线、粗细不匀描边等手绘痕迹残留

## 6. 边界与降级

SVG 矢量复刻有边界。遇到以下情况，先说明边界并与用户确认可接受的抽象层级，再动手：

- 照片、连续色调绘画：只能做轮廓化抽象，无法像素级复刻
- 大面积渐变与光效：渐变仅按色块端点近似
- 文字过多且极小（<10px 视觉尺寸）：按原文逐字复刻但整体尺寸需放大，或确认省略
- 动图、视频帧序列：只复刻单帧

手绘输入不进入上述协商：判定为手绘即按第 3 节净线结构复刻直接执行。

确认结果记录进回复（一句话说明所取层级），随后按 precision-svg 正常执行。

## 7. 输出

1. 完成视觉解析、坐标映射与自检
2. 写出 SVG 文件（命名：用户指定名或按图片内容语义）
3. 回复中报告：文件路径、复刻模式（忠实取色/框架配色，手绘时注明净线结构复刻）、规范化处理项（如字体统一）、降级说明（如有）
