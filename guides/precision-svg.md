# Precision SVG（精确绘制规范）

本文件是所有绘制任务的强制前置规范。目标只有一个：输出即所见，文字不偏移、元素不错位、箭头不歪斜。所有规则服务于这一目标。

## 1. 坐标计划（Coordinate Plan）

输出任何 SVG 元素之前，先在内部完成整幅图的坐标计划。禁止边画边估坐标。

坐标计划包含以下内容，全部推算为显式数值：

1. 画布：viewBox 宽 W 高 H（默认 `0 0 960 H`），四周安全区 ≥ 40 单位
2. 网格结构：行与列的划分、每行/列的起点与跨度
3. 每个节点的边界框：`(x, y, w, h)` 四个数值，由第 2 节的尺寸公式从文本内容算出
4. 连线走廊：每条连线占用的轨道（避免多条线挤同一走廊）
5. 标签槽位：连线标签、图例、徽章的预留位置
6. 结构容器先于内部节点：容器尺寸由其内部节点的外包矩形加内边距（每侧 ≥ 20）决定

坐标计划在生成过程中保持静默，不出现在用户可见的回复文本中；最终 SVG 文件中也不包含计划注释。

## 2. 文本度量（治文字偏差与溢出）

### 2.1 字符宽度估算表

| 字符类别 | 14px 字号 | 12px 字号 |
|---|---|---|
| 拉丁字母与数字 | 约 8px/字符 | 约 7px/字符 |
| 中文及全角字符 | 约 14px/字符 | 约 12px/字符 |
| 空格与窄标点 | 约 4px/字符 | 约 3.5px/字符 |
| 大写字母、宽符号（W、M、@） | 约 11px/字符 | 约 9.5px/字符 |

修正系数：

- 代码串、标识符、数学符号、URL：估算值 × 1.3
- 混合中英文：按字符类别分段累加
- 多行文本：逐行估算，取最大行宽

### 2.2 节点尺寸公式

```
节点宽 = max(各行文本估算宽) + 左右内边距（合计 ≥ 24）
节点高 = 行数 × 行高 + 上下内边距（合计 ≥ 16）
```

行高按字号 token 的行高取值（14px/20px、12px/18px）。含标题加副标题两行文本的节点，高度 ≥ 56。

先量文本、后定节点、再排布局。禁止先画固定大小的节点再往里塞文字。

### 2.3 文本锚点语义（text-anchor）

每次输出 `<text>` 前，先确定锚点语义，再由语义计算 x 坐标：

| text-anchor | x 坐标的含义 | 典型场景 |
|---|---|---|
| `start`（默认） | 文本左缘 | 左对齐的列表、轴标签 |
| `middle` | 文本水平中心 | 节点内居中文本、轴刻度、数值标签 |
| `end` | 文本右缘 | 右对齐数值、条形图右端标签 |

常见错误：按"居中"预期摆放文本，却未声明 `text-anchor="middle"`，导致文本整体向右偏出节点。节点内居中文本必须同时满足：`x = 节点中心x` 且 `text-anchor="middle"`。

### 2.4 基线控制

`<text>` 的 `y` 坐标是文本基线位置，禁止把"期望的文本垂直中心"直接当作 y。

- 文本垂直居中公式：`y = 容器中心y + 字号 × 0.35`
  - 14px 文本：`y = 中心 + 5`；12px 文本：`y = 中心 + 4`
- 文本顶对齐：`y = 容器顶 + 字号`（首行基线距顶约一个字号）
- 双行文本（标题 + 副标题）：标题基线 `y = 中心 - 4`，副标题基线 `y = 中心 + 16`（14px/12px 组合）
- 不使用 `dominant-baseline` 与 `alignment-baseline`（渲染器实现不一致），统一手算基线偏移

### 2.5 多行文本

SVG 无自动换行。多行文本逐行输出 `<tspan>`：

```xml
<text x="锚点x" y="首行基线y" text-anchor="middle">
  <tspan x="锚点x" dy="0">第一行</tspan>
  <tspan x="锚点x" dy="20">第二行</tspan>
</text>
```

每个 `tspan` 显式携带 `x`（继承锚点语义）与 `dy`（相对上一行的行高）。换行位置由坐标计划决定，换行后的行宽须重新代入 2.2 公式验证节点尺寸。

## 3. 对齐规范（治元素错位）

### 3.1 同排对齐基准

同一排的节点必须统一采用一种对齐基准，全图保持一致：

- 垂直中心对齐（默认）：`y_i = 排中心 - h_i / 2`
- 顶对齐：`y_i = 排顶`
- 底对齐：`y_i = 排底 - h_i`

不等高节点混排时禁止"看起来差不多就行"，必须按基准计算后取整。

### 3.2 等距分布公式

```
总宽 = n × 节点宽 + (n - 1) × gap
节点 i 的 x = 起点 + i × (节点宽 + gap)
```

各 gap 必须相等。禁止肉眼估计间距。

### 3.3 连线端点锚定

连线端点必须落在节点边缘上，按连线离开/进入方向取边缘锚点：

| 连线方向 | 起点锚点 | 终点锚点 |
|---|---|---|
| 向右 | `(x + w, y + h/2)` | `(目标x, 目标中心y)` |
| 向左 | `(x, y + h/2)` | `(目标x + 目标w, 目标中心y)` |
| 向下 | `(x + w/2, y + h)` | `(目标中心x, 目标y)` |
| 向上 | `(x + w/2, y)` | `(目标中心x, 目标y + 目标h)` |
| 斜向 | 边缘最近交点 | 边缘最近交点 |

矩形边缘交点计算：以目标中心为参考，按连线斜率求与四边的交点，取连线方向上的那个。

禁止端点悬空在空白处，禁止端点深入节点内部。

## 4. 箭头规范（治箭头歪斜）

### 4.1 标准 marker 唯一定义

全图使用同一个 marker 定义（放在 `<defs>` 内）：

```xml
<defs>
  <marker id="arrow" viewBox="0 0 8 8" refX="7" refY="4"
          markerWidth="8" markerHeight="8"
          markerUnits="userSpaceOnUse" orient="auto">
    <path d="M1 1 L7 4 L1 7 Z" fill="context-stroke"/>
  </marker>
</defs>
```

- `orient="auto"`：箭头自动沿路径末端方向旋转。向右、向左、向上、斜向、曲线末端的箭头全部由路径方向决定，不需要也不可能画歪
- `markerUnits="userSpaceOnUse"`：箭头尺寸不随线宽缩放
- `fill="context-stroke"` 在部分渲染器不支持时，改为与连线同色的显式 fill，并可按连线颜色定义多个 marker（如 `arrow`、`arrow-brand`）

### 4.2 附着规则

- 箭头通过 `marker-end="url(#arrow)"` 附着在连线同一条路径上。箭头与线是一个整体，禁止把箭头画成独立三角形再手动旋转摆放
- 双向关系画两条路径，各带 `marker-end`；禁止一条路径加两个分离箭头
- 起点标记（如圆点）用 `marker-start`，同样在 `<defs>` 中定义

### 4.3 端点缩进规则

目标端点从节点边缘向连线方向回退 1~2 单位，避免箭头尖端刺入或压住节点边框：

```
终点 = 节点边缘锚点 - 2 × 单位方向向量
```

水平向右的连线：终点 x = 目标左缘 x + 2（marker refX=7 使箭头尖恰在路径终点，回退后箭头尖贴近但不压线框）。

### 4.4 禁止事项

- 手绘三角形箭头（`<polygon>` 旋转摆放）
- 装饰性括号、双曲线、花括号当箭头
- 分离的 chevron（V 形折线）叠在直线上
- 复制一个右向三角到向左/向上的连线上而不旋转

### 4.5 曲线与拐弯

- 贝塞尔曲线（`C`/`Q`）：控制点须使曲线沿水平或垂直方向离开起点、沿水平或垂直方向进入终点，保证出入角度与节点边缘自然衔接
- L 形拐弯：用圆角替代直角。优先用二次贝塞尔（`Q`）在转角处做半径 ≥ 12 的圆角，或用一条 `path` 内的多段 `Q` 命令
- 绕行：连线必须绕过无关节点与文本，宁可多拐一次弯，禁止穿越
- 跨行斜线：消息、状态转移的端点在不同行时允许斜线，方向由端点自然决定，禁止强行拉平

## 5. 防重叠硬门禁（Hard Fit Gate）

以下为不可违反的硬约束。任何一条无法满足时，缩减内容（缩短标签、合并节点、拆分图形、改为表格）后重排，禁止通过缩小字号、压缩间距、裁剪溢出、遮挡碰撞来硬塞。

间距下限：

| 关系 | 最小 gap |
|---|---|
| 同排相邻无关节点 | 32 |
| 同排相邻流程步骤 | 60 |
| 同列上下相邻节点 | 28 |
| 同列且中间有连线标签 | 56 |
| 连线标签胶囊与线身 | 8 |
| 容器边缘与内部节点 | 20 |

重叠禁令：

- 任意两个边界框（节点、标签、徽章、图例、胶囊）不得相交
- 连线不得穿越任何节点与文本
- 连线标签不得压在线身上：标签置于线上方或下方的胶囊中，胶囊与线身距离 ≥ 8
- 禁止用背景色矩形遮盖碰撞（白底遮线、遮字）
- 图例、阶段标签、注释面板必须占坐标计划中的独立槽位，禁止浮在连线走廊上

画布约束：

- viewBox 高度 H = 最低可见元素（含文本基线）+ 底部安全距（≥ 40）
- 禁止负坐标
- 禁止为容纳长标签缩小 viewBox 再裁剪
- 底部禁止大面积无解释空白
- 极坐标图形（饼、环、雷达）的图形容器不拉伸至全宽，保持自然纵横比居中

## 6. 结构与复用

- `<defs>`：marker、渐变（仅限连续物理变量）、可复用形状统一定义于此，全图引用
- `<g>` 语义化分组：按逻辑单元分组（`<g id="step-1">`、`<g id="legend">`），便于坐标核对
- 描边默认：`stroke-width` 1.5，`stroke-linecap="round"` `stroke-linejoin="round"`，连线 `fill="none"`
- 线型语义：实线 = 标准依赖/调用；虚线 = 可选/弱依赖/异步；品牌色线 = 焦点路径。每图线型 ≤ 2 种
- 网格线、刻度线用 `--border` 色；轴与文本用 `--text-muted`；关键数值用 `--text`

## 7. 输出前自检清单

输出文件前逐项核对，任何一项不通过则回到坐标计划修正：

1. 坐标计划已完成，所有节点有显式 `(x, y, w, h)`
2. 每个节点的尺寸由其文本按 2.1/2.2 公式算出，无文本溢出
3. 每个 `<text>` 的锚点语义与 x 计算方式一致；基线按 2.4 公式计算
4. 同排节点对齐基准一致；各 gap 相等且满足 5 的下限
5. 所有箭头使用标准 marker + `marker-end`，端点缩进 1~2 单位
6. 任意两个边界框不相交；无连线穿越节点或文本
7. 连线标签在胶囊中且与线身 ≥ 8
8. viewBox 覆盖全部元素 + 安全区；无负坐标
9. 颜色全部 `var(--token)`（复刻任务按取色规则执行）
10. 图形在深浅背景下均可读（文本与底面对比度足够）
