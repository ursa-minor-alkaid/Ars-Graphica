# architecture-container — 容器嵌套架构图示例

演示 precision-svg.md 在容器嵌套架构图上的完整应用。占位配色为灰阶 + 单一演示蓝，正式配色由 `tokens/visual-tokens.md` 填写后决定。

## 演示的技术点

| 技术点 | 对应规范 | 本图中的体现 |
|---|---|---|
| 容器先于节点定位 | precision-svg §1 | 边界容器 (240,140,520,264) 先定，内部模块按容器内边距（每侧 ≥ 20）排布 |
| 容器内边距门禁 | §5 | 左 40、右 40（转换器右缘 720 vs 容器右缘 760）、下 20（行 2 底 384 vs 容器底 404） |
| 同列 gap 门禁 | §5 | 行 1 底 264 到行 2 顶 320，gap = 56（中间走 L 弯连线） |
| 双行文本节点 | §2.5 | 标题基线 = 中心 − 4，副标题基线 = 中心 + 16，tspan 语义由两个独立 text 元素承担 |
| L 弯圆角绕行 | §4.5 | 转换器到存储器：竖出 → Q 圆角 → 横行 → Q 圆角 → 竖入，全程不穿任何节点 |
| 外部块置于容器外 | text-to-figure §3.6 | "用户上传""报表服务"在容器两侧，连线穿过容器边框完成进出（语义正确） |
| 线型预算 | §3.6 / §6 | 恰好两种线型（实线、虚线）+ 品牌色焦点线；每条线配独立 marker（灰/品牌色） |
| 连线标签胶囊 | §5 | "异步""结果"标签在白底胶囊中，与线身距离 11（≥ 8） |
| 图例独立槽位 | §5 | 图例底板 (208,432,544,36) 占容器下方独立行，与容器底 gap = 28 |
| 单一焦点 | text-to-figure §2 | 唯一品牌元素组合 = 存储器节点 + "主数据流"连线（同一焦点的两种表达） |

## 坐标计划摘要

| 元素 | x | y | w | h | 备注 |
|---|---|---|---|---|---|
| 用户上传（外部） | 60 | 204 | 120 | 56 | 中心 y=232，与行 1 对齐 |
| 处理集群（边界） | 240 | 140 | 520 | 264 | 虚线，rx=12 |
| 校验器 | 280 | 200 | 160 | 64 | 行 1 左 |
| 转换器 | 560 | 200 | 160 | 64 | 行 1 右，与校验器 gap=120 |
| 存储器（焦点） | 420 | 320 | 160 | 64 | 行 2 居中 |
| 报表服务（外部） | 800 | 324 | 120 | 56 | 中心 y=352，与存储器对齐 |

连线：

1. 用户上传 → 校验器：水平线 (180,232)→(278,232)，穿容器左边框进入
2. 校验器 → 转换器：水平虚线 (440,232)→(558,232)，标签"异步"在线上方胶囊
3. 转换器 → 存储器：L 弯 `M 640 264 L 640 272 Q 640 292 620 292 L 520 292 Q 500 292 500 312 L 500 318`，走廊 y=292 位于行 1 与行 2 间隙带正中（两侧各距 28），两处 Q 圆角（r=20）分别完成"向下转左""向左转下"的切向衔接
4. 存储器 → 报表服务：品牌色水平线 (580,352)→(798,352)，穿容器右边框输出，标签"结果"在线上方胶囊

viewBox 高度 = 图例底板底 468 + 安全距 → 510。

## 可替换点

- 模块数量：容器内 ≤ 6 个未分组模块；更多时先分组再加容器层（嵌套 ≤ 3 层）
- 焦点位置：焦点模块与主数据流线应指向同一元素，更换时两者一起移动
- 图例项：线型或块型超过 2 种时必须保留图例；不超过时可删除图例并回收纵向空间
