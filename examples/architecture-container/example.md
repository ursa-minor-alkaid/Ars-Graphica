# architecture-container — 容器嵌套架构图与判定分支示例

演示 precision-svg.md 在容器嵌套架构图上的完整应用，并在同一幅图中并入流程图的判定分支要素。配色取自 `tokens/visual-tokens.md` 的方案一「雾蓝燕麦」：中性模块用 `--surface-muted`，外部块与标签胶囊取画布同色 `--surface` 形成描边式空块，焦点模块用 `--brand-soft-strong` 配 `--brand` 描边，连线用 `--text-muted` 与 `--brand` 两色区分依赖与主数据流。切换配色方案时替换文件顶部声明块中的颜色值即可，几何坐标不受影响。

| 元素 | x | y | w | h | 备注 |

行 1 垂直中心一律 y=232（模块 200~264，菱形 196~268，中心同为 232）；行 2 中心 y=392。

连线：

1. 用户上传 → 校验器：水平线 (160,232)→(263,232)，穿容器左边框进入
2. 校验器 → 合格？：水平线 (361,232)→(419,232)，终点自菱形左顶点 421 回退 2
3. 合格？ → 转换器（是）：水平线 (539,232)→(597,232)，起点为菱形右顶点 539
4. 合格？ → 驳回队列（否）：`M 480 268 L 480 308 Q 480 328 460 328 L 125 328 Q 105 328 105 348 L 105 478`，从菱形下顶点竖直下行，经走廊 y=328 左折，再竖直下行至驳回队列顶边
5. 转换器 → 存储器：`M 647 264 L 647 280 Q 647 300 627 300 L 520 300 Q 500 300 500 320 L 500 358`，两处 Q 圆角（r=20）完成切向衔接，自存储器顶边 x=500 处进入
6. 存储器 → 报表服务：品牌色水平线 (528,392)→(798,392)，穿容器右边框输出

冲突校验：走廊 y=300 横段占 x 520~627，"否" 分支竖段在 x=480，两者最近距离 40；"否" 分支横段 y=328 与走廊 y=300 相距 28；存储器顶边 y=360 与横段 y=328 相距 32。

viewBox 高度 650 = 最低元素（图例底边 604）+ 安全距 46。

## 可替换点

- 模块数量：容器内未分组模块 ≤ 6 个；更多时先分组再加容器层（嵌套 ≤ 3 层）
- 判定节点增删：删除"合格？"后行 1 回到两模块布局，须重算等距分布与容器宽度；增加第二个判定时走廊数随之增加，须重新分配 y 坐标
- 焦点位置：焦点模块与主数据流线应指向同一元素，更换时两者一起移动
- 图例项：块型或线型超过 2 种时必须保留图例；不超过时可删除图例并回收纵向空间（viewBox 高度随之减 116）
- 文字变更：改标签后必须按 §2.2 重算节点宽度，再按 §3.2 重算等距分布，禁止沿用旧坐标
