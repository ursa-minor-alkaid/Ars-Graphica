# dio-construct — DIO 基因结构机制图示例

演示 precision-svg.md 在分子生物学基因结构上的机制图应用，兼作生命科学领域范例。配色取自 `tokens/visual-tokens.md` 的方案二「豆绿陶土」（该方案的推荐场景即生命科学类内容）：loxP 用中档 `--chart-series-3`，lox2272 用浅档 `--chart-series-2`，GOI 用深档 `--chart-series-1` 配 `--brand-on` 白字，主干线与启动子走中性层的 `--text-muted`。三个元件共用同一灰绿色相、按明度阶梯区分，构成“同色相三档”编码；切换配色方案时替换文件顶部声明块中的颜色值即可，几何坐标不受影响。

## 演示的技术点

| 技术点 | 对应规范 | 本图中的体现 |
|---|---|---|
| 画机制本身 | text-to-figure §3.4 | 删去全部文字后，三角朝向、箭尖方向与色阶仍可读出“两对异型位点夹持反向 GOI”的结构 |
| 位点方向语义 | text-to-figure §3.4 | loxP 与 lox2272 画为三角指向符号，两对异型位点头对头排布（左侧 ▷、右侧 ◁），方向差异不依赖文字即可读出 |
| 反向 GOI | text-to-figure §3.4 | GOI 为尖端朝左的五边形块，与启动子的转录方向相反，表达“反向插入、默认不读码” |
| 标准 marker 箭头 | precision-svg §4.1 / §4.3 | 启动子折线末端附着唯一定义的 arrow marker（`orient="auto"` 自动定向），不手绘三角形 |
| 轴线对称 | precision-svg §3.1 | 三角高 52，沿轴线 y=210 上下各 26，垂直中心线与轴线重合 |
| 文本锚点语义 | precision-svg §2.3 | 图内全部文本 `text-anchor="middle"`，x 取所属元件的几何中心（三角 212~248 → 标签 x=230） |
| 基线控制 | precision-svg §2.4 | GOI 文本基线 215 = 块中心 210 + 5（14px 垂直居中修正）；位点标签基线 262 = 三角底 236 + 26 |
| 同色相三档编码 | tokens 颜色用法规则 | loxP / lox2272 / GOI 依次取 `--chart-series-3` / `--chart-series-2` / `--chart-series-1`，同一灰绿色相拉开明度阶梯，每个颜色都有标签命名 |
| 白字对比度 | precision-svg §7.10 | GOI 深绿底（`#516A57`）上的白字对比度约 5.9:1，直接铺 `--brand-on` 即可 |
| 单一焦点 | text-to-figure §2 | 面积最大、明度最深的 GOI 是唯一焦点；位点与启动子保持浅色与中性 |
| viewBox 高度 | precision-svg §5 | H=360 = 最低元素（图注基线 318）+ 安全距 42 |

## 坐标计划摘要

画布 960×360，主干轴线 y=210，四周安全区不小于 40。

| 元素 | x | y | w | h | 备注 |
|---|---|---|---|---|---|
| DNA 主干线 | 80 | 210 | 800 | — | 水平基线 |
| 启动子折线 | 110 | 168 | 54 | 42 | 竖段 210→168，横段带箭头至 164 |
| loxP（左） | 212 | 184 | 36 | 52 | 三角右指，中心线 y=210 |
| lox2272（左） | 312 | 184 | 36 | 52 | 与左侧 loxP 间距 64 |
| GOI（反向） | 430 | 178 | 200 | 64 | 尖端 (430,210)，主体 452~630 |
| loxP（右） | 692 | 184 | 36 | 52 | 三角左指 |
| lox2272（右） | 792 | 184 | 36 | 52 | 与右侧 loxP 间距 64 |
| 位点标签 | — | 262（基线） | — | — | 四个标签对位三角中心 x = 230 / 330 / 710 / 810 |
| 底部图注 | — | 318（基线） | — | — | 12px，居中 x=480 |

相邻间距：248→312 = 64，348→430 = 82，630→692 = 62，728→792 = 64，均满足同排间隙下限；GOI 箭尖轮廓细窄、视觉重量低，故留距略大于其余三处。主干线两端余量：左 30、右 52。

## 可替换点

- 基因元件：GOI 名称改长时按 §2.2 重算五边形宽度并重排两侧位点，保持 60 以上间距
- 元件数量：增删位点时重算全部间距，再核对主干线两端余量（现为左 30、右 52）
- 配色：切换方案时替换顶部 token 声明块；若改为单焦点配色，把三个元件统一压回 `--brand`，靠形状与标签区分
- 方向翻转：改为 DO 结构时把 GOI 箭尖翻向右，并同步翻转右侧一对位点的三角朝向
