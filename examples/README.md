# Examples（示例库）

三个静态 SVG 示例，作为生成任务的起手骨架参考。每个示例包含：

- `figure.svg`：完整独立 SVG 文件，可直接在浏览器打开
- `example.md`：该图应用的规范条目对照、坐标计划摘要、可替换点

| 示例 | 图形类型 | 重点演示 |
|---|---|---|
| `flowchart-basic` | 横向流程图（含决策分支与失败回环） | 节点尺寸公式、文本锚点与基线、标准 marker 箭头、端点缩进、回环绕行 |
| `chart-bar-line` | 柱状 + 折线双轴组合图 | 纯 SVG 手绘图表、刻度与网格、图例槽位、数值标签锚点、单一焦点 |
| `architecture-container` | 容器嵌套架构图 | 容器先定位、内边距门禁、L 弯圆角绕行、外部块、线型预算、图例 |

## 阅读方式

示例的价值在于坐标可追溯：`example.md` 中的坐标计划摘要展示了每个边界框如何由文本度量与间距公式算出，与 `guides/precision-svg.md` 的规则逐条对应。生成新图形时，选最接近的示例作为骨架，替换内容后按同一公式重算全部坐标，禁止沿用旧坐标硬套新文本。

## 演示色说明

三个示例统一使用灰阶 + 单一演示蓝（`#2563EB`）的占位配色。该配色仅为让示例可打开查看，不构成推荐配色；正式配色由 `tokens/visual-tokens.md` 中的 token 填写后决定。token 填写后，示例中的占位色应替换为对应 token 引用。
